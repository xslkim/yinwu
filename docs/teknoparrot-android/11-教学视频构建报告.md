## 各集内容概要

- **E1**：街机基板本质是 x86 PC（Type X=XP Embedded+DX9 / Lindbergh=Linux / ES3）；TeknoParrot 是兼容层不是模拟器；28 款游戏四条移植路线分组；产品形态三档。
- **E2**：OpenParrotLoader 挂起进程+入口点劫持；JVS 串口偷换命名管道 `\\.\pipe\teknoparrot_jvs`；三条数据通道（Pipe 15ms / JvsState 64 字节共享内存）；加密狗/区域/ALL.Net 三道门的绕过；BudgieLoader+MSYS2 跑 Lindbergh ELF；475 个 profile 的 EmulatorType 分布；After Dark 就地 patch 取证。
- **E3**：Sinden 式 24px 亮边框定位；单应 H 状态；陀螺纯旋转精确传播公式；逐边亚像素测量+五重门控；输出级融合反转（one-euro）；120Hz UDP + 90ms snapshotAhead 预测；相机-IMU 时间戳在线标定；实测指标（抖动 0.11px、可用率 98-100%）。
- **E4**：桥接器四模块；Windows 输入注入三路线对比（SendInput/Interception/虚拟 HID）；TeknoParrot 原生光枪链路（RawInput→JvsState）；两点校准吸收 13px 外缘偏差+安装偏差；WS_EX 置顶透明叠加窗与独占全屏对策；一键启动架构；DemulShooter 参照物。
- **E5**：Box64 dynarec/Wine/DXVK/Turnip 四层翻译栈；性能损耗规律与 GTA V 实测；GPU 驱动生死线（Adreno✅/RK3588🟡/Amlogic❌）；Winlator 纯 Java X Server 架构；injectPointer 集成点与 1:1 坐标直通；LGPL-2.1 边界；fork 收口与 C1-C4 里程碑。

## 构建过程记录

- 环境修复：Agent CLI provider 从 kimi-cli（未安装）切换为 claude-cli（`autovideo.config.json`）；VoxCPM2 TTS 服务 GPU 常驻（127.0.0.1:8000）。
- 管线：每集 compile → tts（VoxCPM2，音色 B00.wav）→ visuals（claude CLI 逐块生成 React 组件，含类型检查与评审）→ render（Remotion/Chromium 逐块渲染 → concat → loudnorm 响度归一化）。
- 脚本阶段：5 集并行编写 + 一轮交叉引用统一（系列地图/下集预告/发音词典），compile 5/5 通过、发音 lint 清零。
- 构建阶段历时约 5 小时（视觉组件生成是瓶颈，~6-19 分钟/块，共约 60 块），经历 3 次 Agent 超时接力 + 1 次额度耗尽恢复，缓存断点续跑机制保证了零返工。
- 修补记录：无人工修补——全部块一次渲染通过（E3 记录：12 renders, 0 failures）。
- 发音词典：各集 dict.md 覆盖 TeknoParrot/JVS/Box64/DX9/ARM64/LGPL 等术语读音。
