# 12. 新机器部署指南（第二台 PC 运行全部游戏）

本文档面向：在**另一台 Windows 机器**上部署"手机光枪 + TeknoParrot 街机游戏"整套环境。
前提：新机器已经 `git clone https://github.com/xslkim/yinwu.git`，并且游戏文件（各游戏目录 + TeknoParrot 1846）已经在本地。

> 仓库里**不含游戏文件**（.gitignore 白名单制，只收录 `tvgun-bridge/`、`docs/`、`container/` 等），游戏必须由你本地提供。

## 0. 一图看懂部署物

```
<安装根目录>（默认 D:\yinwu）
├── 1846\                        ← TeknoParrot 1.0.0.1846（游戏文件自带，不在 git）
│   ├── TeknoParrotUi.exe
│   └── UserProfiles\*.xml       ← 27 款游戏的 TeknoParrot 配置（记录游戏 exe 路径）
├── Ghost Squad Evolution\ ...   ← 27 个游戏目录（不在 git）
├── tvgun-bridge\                ← git 仓库内容：桥接器源码
│   ├── setup-admin-once.bat     ← 一次性管理员配置
│   └── tools\make-launchers.sh  ← 一键启动器生成器
└── 启动游戏.bat / 游戏大厅.bat   ← 由生成器写入各游戏目录 / 根目录（不在 git）
```

## 1. 目录约定（最重要）

所有配置里的路径默认都是 `D:\yinwu`：

- 桥接器的 27 份游戏适配文件 `tvgun-bridge/src/TvgunBridge.Core/games/*.json` 中 `gameDirectory`、`teknoParrotIniPath`；
- TeknoParrot 侧 `1846/UserProfiles/*.xml` 里的游戏 exe 路径。

**强烈建议新机器也使用 `D:\yinwu` 作为安装根目录**，保持与开发机完全相同的目录结构，这样零改动即可运行。如果做不到，见文末"附录 A：换路径"。

目录结构要求（以 GSEVO 为例）：`D:\yinwu\Ghost Squad Evolution\Ghost Squad Evolution\vsg_l\` 是游戏目录，`D:\yinwu\1846\TeknoParrotUi.exe` 存在。各游戏的预期目录就是 `games/*.json` 里的 `gameDirectory`。

## 2. 安装依赖（3 个）

| 依赖 | 用途 | 安装 |
| --- | --- | --- |
| .NET 9 SDK | 编译桥接器 | https://dotnet.microsoft.com/download （`dotnet --version` 应 ≥ 9.0.100） |
| Git Bash | 运行生成器/验证脚本 | Git for Windows 自带，clone 过仓库就说明已有 |
| Python 3 | 生成器解析 JSON | https://www.python.org/downloads/ （装完 `python --version` 可用） |

## 3. 部署步骤（约 10 分钟）

```bash
# 1) 编译桥接器（Release，生成器生成的 bat 指向 Release 输出）
cd /d/yinwu/tvgun-bridge          # Git Bash 里 D:\yinwu 写作 /d/yinwu
dotnet build -c Release

# 2) 可选但强烈建议：跑测试确认环境健康（196 个用例，约 1 分钟）
dotnet test

# 3) 生成 27 个一键启动器 + 游戏大厅菜单
bash tools/make-launchers.sh
# 预期输出 27 行 wrote: ...启动游戏.bat + wrote: D:/yinwu/游戏大厅.bat
# 如果游戏没放在 D:\yinwu：TVGUN_ROOT=<你的根目录> bash tools/make-launchers.sh

# 4) 一次性管理员配置（urlacl + 防火墙放行 TCP/UDP 8000、UDP 8001）
#    在文件管理器里右键 tvgun-bridge\setup-admin-once.bat → 以管理员身份运行
#    （漏了这步也没关系：首次双击任一"启动游戏.bat"会自动弹 UAC 提权补跑）
```

完成后验证一次真机全链路（约 2 分钟，需桌面未锁屏）：

```bash
bash tools/e2e-realgame.sh --run run1   # 自动启动 GSEVO、模拟手机开枪、断言退出
```

## 4. 手机端

手机端与 PC 无关仓库无关，只需 APK：

- 直接拷贝开发机上的 `D:\tvgun\android\tvgun.apk` 到手机安装；
- 或从源码构建：`git clone https://github.com/xslkim/tvgun.git`，按其中说明打包。

手机与 PC 连**同一局域网**。App 支持自动发现（UDP 8001 广播），发现不到就手动填 PC 的局域网 IP（`ipconfig` 查看）。手机四角按键：左下 投币/开始，右下 换弹/退出（退出需双击防误触）。

## 5. 日常使用

双击任意游戏目录里的 `启动游戏.bat`，或在 `D:\yinwu` 根目录双击 `游戏大厅.bat` 选号。bat 全自动完成：管理员环境自检 → 杀残留 TeknoParrotUi → 起桥接器（写 ini、协议服务、注入、无边框+白边）→ TeknoParrot 直启游戏。游戏退出 10 秒后桥接器自动收场。

注意：

- 玩的时候**不要锁屏**（锁屏下游戏图形初始化失败、注入无法到达）。
- 日志在 `%APPDATA%\TvgunBridge\bridge.log`，排障先看它（关键行：`SERVER_LISTENING`、`WINDOW_FOUND`、`INJECTION_ENABLED`）。

## 6. 常见问题

| 症状 | 原因与处理 |
| --- | --- |
| bat 提示 Bridge exe not found | 没编译 Release，回到第 3 步第 1 条 |
| 手机搜不到 PC / 打枪没反应 | 防火墙没放行：管理员重跑 `setup-admin-once.bat`；确认手机与 PC 同网段 |
| 桥接器日志 `SETUP_MISSING` | urlacl 缺失，管理员重跑 `setup-admin-once.bat` |
| 游戏起不来但 TeknoParrot 界面正常 | `1846\UserProfiles\<游戏>.xml` 里的 GamePath 与实际不符（路径与开发机不一致时出现），在 TeknoParrotUi 里重新指一下游戏 exe |
| make-launchers.sh 报 python not found | 装 Python 3，或 `TVGUN_PY=/路径/python bash tools/make-launchers.sh` |
| 个别游戏窗口不铺满/不识别 | 该游戏窗口标题与适配 JSON 的 `windowTitleRegex` 不符，看 bridge.log 的 `WINDOW_FOUND` 行 |

## 附录 A：换路径（游戏不在 D:\yinwu 时）

假设根目录改为 `E:\games\yinwu`，需要改三处：

1. **适配 JSON 批量替换**（27 份，Git Bash 中执行）：

   ```bash
   cd /e/games/yinwu/tvgun-bridge/src/TvgunBridge.Core/games
   python - <<'EOF'
   import glob
   for f in glob.glob('*.json'):
       s = open(f, encoding='utf-8').read()
       s = s.replace(r'D:\yinwu', r'E:\games\yinwu')
       open(f, 'w', encoding='utf-8').write(s)
   print('done')
   EOF
   ```

   （注意 JSON 里的反斜杠是成手转义的 `\\`，上面按原始字符串替换即可。）

2. **TeknoParrot 配置**：把 `1846\UserProfiles\*.xml` 中游戏 exe 路径改到新位置（可用 TeknoParrotUi 界面逐款重指，或文本批量替换）。

3. **重新生成启动器**：`TVGUN_ROOT=E:/games/yinwu bash tools/make-launchers.sh`。

## 附录 B：最小文件清单（新机器需自备的非 git 文件）

- `1846\` 完整目录（TeknoParrot 本体 + `UserProfiles\*.xml`）
- 27 个游戏目录（目录名与 `games/*.json` 的 `gameDirectory` 一致）
- 手机 APK（`tvgun.apk`）

其余（桥接器、脚本、文档）全部来自 git 仓库。
