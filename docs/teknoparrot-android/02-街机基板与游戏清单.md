# 02 - 街机基板技术规格与游戏清单对照

> 调研目的：为"把 TeknoParrot 上运行的街机光枪游戏移植到 Android 智能电视"制定可行方案，
> 先搞清楚每款游戏原生运行的基板 / 操作系统 / CPU / GPU / 图形 API。
>
> 调研方法：
> 1. 网络资料（system16.com、维基百科、Sega Retro、TeknoParrot 官方兼容性列表、arcade-docs 等，URL 附后）；
> 2. **本地取证**：直接检查 `D:\yinwu` 下每款游戏目录里的可执行文件格式（PE/ELF）、DLL、脚本、引擎特征文件，
>    与网络资料交叉验证（例如 `bowling_usa` 经 `file` 命令确认为 32 位 Linux ELF）。
>
> 数据日期：2026 年。标注"未确认"的条目表示公开资料缺失，已给出推断依据。

### 1.6 Konami PC Based（本清单出现 5 次，重要）

Konami 2003 年后大量街机直接用 PC 主板 + Windows XP Embedded，TeknoParrot 统一标注为 "Konami PC Based"：

- OS：**Windows XP Embedded**（少量后期机型 Windows Embedded Standard 2009）
- API：**DirectX 9.0c**；引擎多为 Konami 自研 FGL（本地 `ByonByon/bin/fgl.dll`、`bbfgl.dll`、`eamuse.dll` 可证）
- 已知具体型号 "Longhorn"（Cooper's 9 所用）：Pentium 4 2.4B GHz、DDR 256MB、**NVIDIA GeForce4 MX 440-8X（AGP，仅 DX7 级）**、60GB IDE HDD、Windows XP Embedded
- 输出：640×480 为主

来源：[System16 Konami PC Based（含 Cooper's 9 完整规格）](https://www.system16.com/hardware.php?id=587)、[arcade-docs/konami/boards.md](https://github.com/shizmob/arcade-docs/blob/main/konami/boards.md)、[Reddit：Konami 街机用 XP Embedded](https://www.reddit.com/r/windowsxp/comments/n8ffc7/)

## 3. 按移植难度分组

### a) Windows x86 32 位 + DirectX 9（最容易，共 16 款）

原生就是"低配 PC 游戏"，GPU 要求最高不超过 GeForce 7600GS / HD 6770 级，分辨率 ≤720p。
Android 路线：**Winlator / GameHub / Mobox（Box64+Wine+DXVK→Vulkan）**，DX9 经 DXVK 转 Vulkan 效率最高，中端骁龙（如 8 Gen 系列电视盒）足以 60fps。

- Action Deka、ByonByon、Gashaaaan!!!!、Gashaaaan Refill!、Wartran Troopers、Cooper's 9（DX7 级 GPU，最轻松）
- Haunted Museum / Haunted Museum II（Type X2，DX9.0c，720p 上限）
- Aliens: Extermination（XP 32bit，VM 都能跑）
- Friction、Bug Busters、Pull The Trigger、Robin Hood、Akuma
- After Dark（DX9/Virtools，1080p 但引擎古老）
- Medaru no Gunman（RingWide，DX9 SM4.0，720p）
- Block King Ball Shooter（DX9，720p 推断）

### b) Windows x64 + DirectX 11（中等难度，共 3 款）

Unity 引擎 1080p 游戏，需要 DX11→Vulkan 转译（DXVK）且 CPU 单核性能要求更高；智能电视芯片（Amlogic S905/S928、Rockchip RK3588）跑 Winlator 会吃力，建议高端骁龙平台或等 GameHub 类方案成熟。

- Point Blank X（ES4，Unity，Win8.1/Win10 64bit）
- Wild West Shootout（Unity，Win64）
- Family Guy Bowling（Unity；**注意它原生带 Linux x86_64 二进制**，可尝试 Box64 + 原生 Linux 用户态直接跑，绕过 Wine/DXVK，是本组里最有希望的一款）

### c) Linux ELF（Lindbergh / Raw Thrills / Paokai，共 4 款）

- Ghost Squad Evolution、Primeval Hunt（Lindbergh Red，OpenGL 2.x + NVIDIA Cg）
- Big Buck Hunter Pro（Raw Thrills Linux，OpenGL）——若用原始街机镜像
- Go Go Strike（Paokai，i386 ELF，Allegro 软渲级）

Android 路线两条：
1. **lindbergh-loader**（开源项目，已能把 Lindbergh 游戏跑在现代 Linux 上，本质是 ELF 兼容层而非模拟器）理论上可移植到 ARM Linux + Box64 + gl4es/NVIDIA Cg→GLSL 转换，但 Cg shader 转换是主要工作量；
2. 或者在 Android 的 Linux chroot/proot 里 Box64 + Wine 思路的 Linux 版（Box64 + gl4es）直接执行 ELF。
性能要求本身很低（7600GS 级 OpenGL 2.x），瓶颈在兼容层移植，不在算力。

### d) 其他特殊（需主机模拟器，共 1 款）

- Vampire Night（Namco System 246 = PS2 基板）：与 PC 移植无关，Android 上直接用 **NetherSX2/AetherSX2（PCSx2 系）** 或 Play! 的 Android 版，光枪映射需单独适配（GunCon 2 → 触屏/蓝牙枪）。TeknoParrot 在 PC 上也是内嵌 Play! 运行它。

## 4. 对 Android 移植的启示小结

1. **这批游戏 86%（24/28）原生就是 x86 PC 游戏**，其中 16 款只需 DX9、640×480~720p，原始硬件是 2004–2012 年的低端 PC（P4/C2D/7600GS 级）。这意味着**没有任何一款需要"模拟街机专用芯片"**——TeknoParrot 本质是破解加载器而非硬件模拟器，移植问题转化为"x86 Windows/Linux 程序如何在 ARM Android 上跑"。
2. **主流可行路径：Winlator / GameHub（Wine + Box64 + DXVK）**。DX9 组（a 组）在骁龙 8 Gen2 级设备上普遍可达 60fps；RK3588/S928 电视芯片 GPU（Mali G610/G710）对 DXVK 支持尚可但 CPU 转译（Box64）是短板，预期 a 组部分可玩、b 组困难。
3. **b 组 3 款 Unity DX11 游戏是性能分水岭**；Family Guy Bowling 因自带 Linux 二进制可绕开 DX 转译，优先试点。
4. **c 组 Linux 游戏算力需求最低，但生态最缺**：lindbergh-loader 是现成的开源突破口（C++，MIT 系许可），值得评估移植到 Android NDK + Box64 的工作量；Go Go Strike 和 Big Buck Hunter Pro 这种 Allegro/OpenGL 1-2 时代的 ELF，gl4es 就能覆盖图形。
5. **光枪输入是独立难点**：街机枪（红外/串口/并口）→ Android 的方案（Sinden 蓝牙枪、Gun4IR、触屏映射、空中鼠标）与基板无关，需在方案文档中单列；TeknoParrot 生态里由 DemulShooter 解决的枪械抽象层，在 Android 上没有现成对应物。
6. **明确排除项**：本清单无 RingEdge/Nu/ALLS/ES3(X) 等高端基板游戏，也无 Triforce/Chihiro 等需 Dolphin 的游戏；唯一主机基板是 Vampire Night（PS2），交给成熟的 PS2 模拟器即可。
7. 数据缺口（标注"未确认"处）：UNIS/GAMEWAX/CAVE/EM-Teck/COVIELSA/ICE/Coastal 七家第三方 PC 基板的官方 CPU/GPU 型号均无公开拆解资料，但这些游戏年代（2001–2018）、文件体积（300MB–1.5GB）与 TeknoParrot 运行要求一致表明它们不超过同时代低端 PC，按 a/b 组估计性能即可；"Big Bug Hunter Pro" 无官方记录，按 Big Buck Hunter Pro Home 的 mod 处理。

### 5.1 DirectX 版本与基板对应关系

| DirectX 版本 | 基板 | 说明 |
|---|---|---|
| DirectX 7/8 硬件级 | Konami "Longhorn"（Cooper's 9） | GeForce4 MX440 只有 DX8.1 硬件管线，游戏实际多用 DX7/8 固定管线，转译压力最小 |
| DirectX 9.0c | Type X / X+ / X2 / X Zero、Konami PC Based 全系、RingEdge / RingWide / RingEdge 2（大部分游戏）、Global VR PC、各国产 PC 基板 | Shader Model 2.0~4.0；DXVK 对该世代支持最成熟 |
| DirectX 11 | Type X3 / X4、Namco ES3 / ES4 / BNA1、RingEdge 2 部分游戏、Unity 系第三方 PC 游戏（Point Blank X、Wild West Shootout、Family Guy Bowling） | 需要 DXVK 1.x+ 或 VKD3D 之外的 D3D11→Vulkan 完整管线 |

| 主机私有 API | Namco System 246（Vampire Night） | 走 PS2 模拟器，与本文其余内容无关 |

### 5.2 存储与加密形态（影响能否在 Android 上启动）

- Type X/X2 游戏为**硬盘 dump + loader 解锁**（iDmacX/JConfig/OpenParrot），游戏本体是明文 PE 文件，Android 侧不需要处理加密狗；
- Ring 系（Medaru no Gunman）原版有 **keychip（USB 加密狗）**，TeknoParrot dump 已绕过，本地目录可见 `keychip/` 模拟文件；
- Namco ES3/ES4 原版有 **TPM + BitLocker + Sentinel HL 加密狗**（Point Blank X 属 ES4），dump 均为解密后镜像；
- Lindbergh 游戏为**明文 ELF + .so 库**（本地 `vsg_l/` 目录可直接看到），无加密，是 c 组的有利条件；
- Vampire Night 的 CHD 是 System 246 DVD 镜像，由 Play! 模拟器直接读取。

### 5.3 TeknoParrot 本体架构（`D:\yinwu\1846\` 取证）

`1846` 目录即 TeknoParrot 1.0.0.1846 安装目录，内含组件揭示了它对不同基板的处理方式：

| 组件 | 作用 | 对应基板 |
|---|---|---|
| OpenParrotWin32 / OpenParrotx64 | DLL 注入式兼容层（I/O 模拟、分辨率补丁） | 所有 Windows 基板 |
| ElfLdr2 | ELF 加载器（在 Windows 上跑 Lindbergh Linux 游戏） | Lindbergh（Ghost Squad Evolution 有专用 Elfloader2 条目） |
| CrediarDolphin | 内置 Dolphin 分支 | Triforce（本清单未涉及） |
| Play | 内置 PS2 模拟器 | System 246/256（Vampire Night） |
| N2 目录 | Namco N2 支持文件 | System N2（本清单未涉及） |
| FFBBlaster | 力反馈/枪械后座输出 | 外设层 |

这印证了 TeknoParrot 的定性：**对 PC 基板是"破解加载器 + I/O 模拟"，只对少量非 PC 基板内嵌真模拟器**。因此移植到 Android 的核心工作量 = Wine/Box64 兼容层 + 光枪输入适配，而非硬件模拟。

注：x86→ARM 转译（Box64）实测损耗约 30–60%，DX9→Vulkan（DXVK）损耗约 10–20%；a 组游戏原始目标是 2004–2012 年低端 PC，即使叠加双重转译，中高端 Android 硬件仍有数倍余量。**真正的瓶颈在软件适配（Wine/Box64 兼容性、光枪输入链路），而非算力。**

## 8. 结论（速览）

- 28 款游戏中 **24 款为 x86 PC 基板**（16 款 DX9 / 3 款 DX11 / 4 款 Linux ELF / 1 款 Unity 双系统），**仅 1 款（Vampire Night）为非 PC 基板**（PS2 架构 System 246）。
- 最高硬件要求仅为 Namco ES4（AMD GX-424CC APU + DX11 1080p，Point Blank X）和 Taito Type X2（C2D E6400 + 7600GS，Haunted Museum）级别——远低于任何一款中端现役手机。
- 推荐技术路线：**a/b 组走 Winlator/GameHub（Wine+Box64+DXVK）；c 组评估 lindbergh-loader 移植或 proot+Box64+gl4es；Vampire Night 走 NetherSX2/AetherSX2**。光枪输入需单独设计（Sinden/Gun4IR 蓝牙方案或触屏映射）。
