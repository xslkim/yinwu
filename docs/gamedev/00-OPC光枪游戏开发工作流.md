# OPC 光枪游戏开发工作流（一人 + AI 全工种）

> 本文是主流程，6 份专项调研（含全部工具链接、授权条款、价格、国内可达性）见同目录：
> r1 引擎技术栈 · r2 AI 策划 · r3 AI 美术 · r4 AI 音频 · r5 AI 编程 · r6 特效打磨测试教程。
> 目标产物：一局 3-5 分钟的 3D 光枪射击游戏，PC 先行，直播间"一眼惊艳"，配合手机光枪套装销售。

## 零、总原则（六份调研的共同结论）

1. **"先做 30 秒好玩"**（Halo 设计师原则）：第一周唯一目标是"瞄准→开火→命中反馈"的爽感循环，核心循环没验证前不做任何 meta 系统（关卡选择/成就/商城一概不做）。
2. **AI 是执行者，你是导演**：每个阶段 AI 产出后由你拍板再继续；demo 到成品之间是鸿沟，AI 让原型小时级、成品仍是月级，时间全花在你的验收和迭代上。
3. **全流程可以 0 元跑通**，建议总预算 ≤¥500（见费用表），只花在真正省时间的地方。
4. **营销不主打"AI 制作"**（伤口碑），主打玩法和直播效果。

## 一、技术底座选型（已定，来自 r1）

- **引擎：Godot 4（GDScript 标准版）**。MIT 免费无分成、离线可用、国内直连；.tscn/.gd 全文本，对 AI 编程最友好；Unity 有 Pro 授权费隐患，UE 过重。
- **玩法结构：Point Blank 式"微关卡串烧"**——10 个左右 20-30 秒微关卡，每关只换一条规则（打靶/禁射人质/时限/连击），同一套瞄准机制规则换皮 = 一人团队最低成本的海量内容，且规则一句话能看懂，天然适配直播。
- **输入抽象（第一天就写）**：`InputProvider` 接口，UDP 枪 / 鼠标 / 触屏 / 手柄四个实现，游戏逻辑只消费"屏幕坐标 + 事件信号"；UDP 收 `x,y` 坐标流 + shot/reload/coin/start 事件（并入 UDP，Godot 无内置 HTTP server）。
- **命中判定**：屏幕空间距离判定为主（`unproject_position` 算像素距离，宽容度可调出街机手感）+ raycast 验遮挡。
- **镜头**：`Path3D/PathFollow3D` 内置做轨道运镜。
- **美术风格：低多边形 + 卡通渲染（toon shader + 描边 + Bloom）**——成本趋近于零、低端电视跑得动、直播惊艳靠高饱和配色+后处理+命中特效，不靠贴图精度。

## 二、十二周计划

### 第 0 周：脚手架（2-3 天）

- [ ] `git init`（git 是生命线：每功能一 commit、每小时至少一 commit）
- [ ] 装 Godot 4 稳定版；跑通两个开源参考项目（r1：crogersdev/rail_shooter_v1 等），把轨道相机和基础射击看懂
- [ ] 写 CLAUDE.md（<200 行，写具体规则含"禁止"清单，不写愿望）——规则模板见 r5
- [ ] 建好 `ATTRIBUTION.md`（素材署名台账，第一天就记）

### 第 1 周：30 秒核心循环

- [ ] 轨道相机 + 鼠标调试模式（隐藏光标+自绘准星）+ 屏幕空间命中判定
- [ ] 一个会移动的靶子 + 命中反馈三件套：**顿帧 30-80ms → 枪口火光+动态光源 → 粒子**（Godot 内置 GPUParticles3D + Tween，r6）
- [ ] 接入 UDP 输入，用手机光枪真实打靶
- [ ] 验收标准：**你拿着手机枪连续打 30 秒不觉得无聊**，达不到就调手感到达为止，别往前走

### 第 2-3 周：垂直切片（1 个完整微关卡 + 全部系统骨架）

- [ ] 纸面策划先行：让 AI（DeepSeek/Kimi/豆包网页版，免费直连够用）按约束脑暴 → 输出 Markdown GDD + 波次表 CSV，**你确认后再动代码**（r2 核心纪律：策划和代码双层修改会让 AI 陷入死循环）
- [ ] 波次管理器（数据驱动：自定义 Resource 定义波次）
- [ ] 素材进场：Quaternius **Toon Shooter Game Kit**（场景）+ **Ultimate Monsters**（50+ 带动画怪物）+ KayKit Skeletons + Kenney Particle/Crosshair 包（全 CC0，r3）
- [ ] 人形角色动画：Mixamo（免费商用）自动绑骨
- [ ] 音效骨架：Pixabay SFX / Mixkit（免费商用免署名、国内直连）+ jsfxr 做 UI 音；枪声三层叠加 + pitch ±5% 随机 + 每音效 3-5 个变体（r4，零成本的专业感分水岭）
- [ ] 命中震动回发手机（差异化卖点，r6）
- [ ] 纯逻辑层（积分/波次/协议解析/滤波）抽离 + AI 写单元测试（GdUnit4 覆盖引擎层）

### 第 4-8 周：内容量产（10 个微关卡）

- [ ] AI 生成波次表 → **实机测试后把实测数据喂回调参，迭代 2-3 轮**（腾讯案例结论：数值 AI 一次给不对）
- [ ] 关卡维护技巧：让 AI 生成带编号的关卡可视化 Web 页，之后用自然语言精确指挥"改 7 号怪血量"
- [ ] BOSS/特色道具：Tripo 或腾讯混元3D（国内直连，AI 生成静态道具可直接进引擎；带骨骼角色必须走"AI 生成→重拓扑→Mixamo 绑骨"流水线）——此时可开一个月订阅集中生成
- [ ] 音乐：开一个月 **Suno Pro（$10，需翻墙）** 集中生成几十首裁成循环（免费版禁止商用；国产海绵/天工条款模糊只能原型用）；自适应音乐 = 同 prompt 同 BPM 生成 3 个强度版，三轨同步按游戏状态交叉淡化（r4）
- [ ] 中文旁白：豆包 TTS（约 ¥2/万字符，一整局 <1 元）
- [ ] 特效升级：Effekseer（MIT 开源，自带 ~300 个日式特效样本，国内直连）

### 第 9-10 周：打磨（polish checklist 见 r6 定制版）

- [ ] 按 "Juice it or lose it" / "The Art of Screenshake" 手法清单逐项过（B站有搬运）
- [ ] **直播观感专项**：特效对比度比本地再夸张 20-30%（对抗直播压缩）；结算画面 + "再来一局 <2 秒"
- [ ] 真人测试：闭嘴观察 3-5 个亲友玩；itch.io / indienova 发 demo 收反馈
- [ ] 稳定性：干净机器从零安装测试；一局掐表 3-5 分钟
- [ ] 授权清理：核对 ATTRIBUTION.md，替换所有"原型占位"素材（BBC 音效、edge-tts、国产 AI 音乐等不可商用项）

### 第 11-12 周：发布预备

- [ ] 15 秒惊艳引流切片（直播投流素材）
- [ ] 接入订单绑定激活（docs/commercial/07）
- [ ] 电视商店/itch.io 上架材料：宣传图用即梦 AI（国内直连），图标用 Kenney Game Icons（别用 AI 生成图标）
- [ ] 抖音直播首播 = 最强 playtest：每场只测一个变量，观众留存曲线和弹幕即真实数据

## 三、每日工作流（AI 协作节奏）

```
上午（创意岗）：  你定方向 → AI 脑暴/出表 → 你拍板 → 写进 GDD/CSV
下午（工程岗）：  AI 实现（小任务粒度，一个功能一个会话）→ headless 运行+截图自检
                 → 你实机验收 → commit
晚上（观察岗）：  自己玩 10 分钟 / 给亲友玩 / 看竞品评论（Steam API 拉评论 + LLM 主题编码）
                 把发现写成明天的任务
```

工程纪律（r5 核心）：任务拆到 AI 一次能完成的大小；复杂场景别让 AI 手写 .tscn（用 GDAI MCP 走编辑器 API）；AI 跑偏时通常是上下文问题不是模型问题；踩坑当天回写 CLAUDE.md。
