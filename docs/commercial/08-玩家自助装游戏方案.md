# 08. 玩家自助装游戏的安全方案（降低摩擦，不碰分发）

> 目标：让买家"自己装好兼容游戏"的过程尽量顺滑，同时公司在法律上始终只是工具提供方。
> 合规红线见 r6 报告与 00 方案生死线 1；本文是红线之内的最佳实践。

## 一、安全梯度：什么能做、什么不能做

法律上定性的关键不是你"知不知道玩家会去玩街机"，而是你**有没有参与游戏文件的分发和诱导**。证据来自：商品页、客服聊天记录、官方群公告、教程内容——这些都是可举证的。

| 行为 | 定性 | 结论 |
| --- | --- | --- |
| 提供自动检测/一键配置/兼容性工具 | 工具功能 | ✅ 安全（RetroArch、Sinden 等同模式） |
| 发布"兼容游戏列表"（仅游戏名+配置方法） | 事实信息 | ✅ 安全 |
| 捆绑自研游戏、已获授权的独立游戏 | 合法内容 | ✅ 安全 |
| 用户社群里玩家互相交流资源 | 用户行为 | ⚠️ 你不组织、不置顶、不转发即可 |
| 教程里写"去 XX 网站下载 ROM" | 帮助侵权/诱导 | ❌ 不做 |
| 客服给买家发资源链接/网盘 | 直接证据 | ❌ 绝不做 |
| 预装、打包、卖硬盘 | 刑事红线 | ❌ 绝不做 |

一句话原则：**摩擦可以靠工具消灭，内容必须从玩家自己手里来。**

## 二、具体方案（五个组件）

### 1. 开箱即有得玩：自带合法内容（最重要）

买家拆开包裹 5 分钟内必须能开枪，绝不能让他们面对"还要自己找游戏"的空窗：

- **自研演示游戏**：1-2 款（打靶/打气球/玩具风休闲射击），随 App 免费装；
- **授权独立游戏**：去 itch.io 找 2-3 款允许再分发的免费光枪/射击独立游戏，联系作者谈捆绑授权（对他们是被窝曝光，通常愿意，成本极低甚至免费）。每款单独核验许可证再捆。

这样"全家桶版 129 元"里的"全部游戏"指的就是这些合法内容，SKU 立得住。

### 2. 游戏库向导：把 TeknoParrot 的配置摩擦消灭

玩家真正的痛点不是"找游戏"（他们自己会找），而是 TeknoParrot 配置繁琐、游戏挑版本、窗口/输入设置劝退。你的工具恰好能把这部分摩擦降到接近零——这正是你 27 款游戏适配工作的价值：

- App/PC 端"游戏库"页：列出全部兼容游戏（只列名字和封面信息）；
- 每款游戏显示状态灯：**自动扫描本地目录**，检测到玩家已有的游戏文件→绿灯，一键配置（写 ini、设 profile、无边框、光枪输入映射，复用 tvgun-bridge 现有能力）；
- 没检测到→灰灯，显示"把你拥有的游戏文件放入指定目录后即可点亮"，**教程到这一步为止**，不写任何获取途径。

### 3. 诊断与排障自动化

- 游戏起不来时的一键诊断：缺运行库、路径错、版本不兼容、配置冲突，给出具体修复建议；
- 这一步把售后客服 80% 的问题挡掉——代发模式下客服成本是你的隐性大头。

### 4. 用户社群：知识让玩家教玩家

- 建买家 QQ 群/Discord，官方身份只聊：你的产品用法、故障排除、新版本；
- 玩家之间交流什么游戏能跑、怎么跑，是用户行为——**官方账号不参与、不置顶、不转发任何资源信息**，群规里写明"禁止发布盗版资源链接"（这句话本身就是你的合规证据）；
- 口碑（"这枪能玩街机"）会在这里自然发酵，这是免费获客，但话不能从官方嘴里说。

### 5. 法律姿态留痕

- App 用户协议写明："本软件不提供任何游戏内容，用户须自行确保其游戏文件来源合法"；
- 商品页、详情页、直播话术统一为："支持多种 PC 光枪游戏""兼容主流光枪游戏平台"，不出现具体街机游戏名和"内置游戏"字样；
- 客服话术库准备标准回复："游戏需要您自行准备哦，我们提供的是光枪设备和适配软件～"

## 三、买家体验全景（确认没有牺牲转化率）

```
拆包 → 手机装 App → 蓝牙连枪 → 自研/授权游戏立刻能玩（5 分钟）
     → 玩上瘾 → 逛游戏库发现"还能玩 XX、XX"（灰灯）
     → 自己动手 → 绿灯点亮，一键配置成功（成就感）
     → 进社群 → 发现更多玩法 → 口碑传播
```

注意这个流程里"灰灯点亮"甚至是个正向的成瘾设计——玩家会把它当成收集目标。你卖的是"点亮所有灯的能力"，合法且体验完整。

## 四、与商业方案的衔接

- 阶段 1 的"自研第一款光枪游戏"优先级不变（演示游戏就是它的雏形）；
- "授权独立游戏捆绑"加入阶段 1 行动清单，成本接近零，能立刻充实"全家桶"SKU；
- 游戏库向导复用 tvgun-bridge 现有 27 款适配 JSON，开发量主要是扫描+状态 UI。
